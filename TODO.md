### Экспорт/импорт
- **Полный текст напоминаний в экспорте.** Сейчас `scheduled_messages` хранит только `text_preview` (~40 символов), поэтому экспортированные напоминания теряют полный текст. Чтобы экспорт был lossless — хранить полный текст напоминания в БД.
- **Импорт OPML** (уже отмечено в README). Поддержать импорт списков каналов в формате OPML (`<outline xmlUrl="https://t.me/s/channel">`) для переноса подписок из RSS-читалок и других Telegram-RSS-ботов; период ставить по умолчанию.

### Дайджесты
- **Управление каналами внутри Telegraph-дайджеста.** Сейчас в больших дайджестах (Telegraph) теряются inline-ссылки «Отписаться/Перенести» по каждому каналу — остаётся только ссылка на «Настройки дайджеста». Добавить компактное управление каналами для Telegraph-версии.
- **Keyword-фильтры на подписку** (include/exclude) — пропускать/прятать посты по стоп-словам (борьба с рекламой/мусором без ИИ). Из исходного списка заимствований (п.4), пока не реализовано.
- **Preview перед подпиской** — при пересылке поста показывать последние N постов канала, чтобы оценить частоту до подписки.
- **Глобальная периодичность по умолчанию** для новых подписок (выбор дефолтного периода/времени), в дополнение к пошаговой настройке после подписки.
