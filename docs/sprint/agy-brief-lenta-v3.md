Задача LV3 — ПЕРЕРАБОТАТЬ макет Ленты: настоящий обзор периода по СЮЖЕТАМ (как лента Твиттера/ВК, но текстом), а не список карточек с метриками. Продолжаем в этой же ветке feat/feed-render-v2,
этот worktree (там уже коммит LV2 — можно перерабатывать его результат). git push запрещён — только локальный коммит. Никаких установок пакетов; ruff и тесты — только
~/.venvs/unagi/bin/ruff и ~/.venvs/unagi/bin/python -m unittest discover -s tests. Секреты, сеть и прод не трогать.
Менять можно ТОЛЬКО feed_render.py (чистые функции, без I/O), тесты рендера (tests/test_feed_render.py и ломающиеся tests/test_feed_t24*.py, tests/test_feed_autodelivery.py), docs/architecture.md (описание страницы),
блок «LV3» в docs/sprint/progress.md. Сигнатуры `render_feed(...)`, `build_feed_title(...)` и поля `FeedItem` (rank, score, post, also_in, badges, channel_title, tag, is_ad) НЕ менять; `also_in` — посты того же сюжета из других каналов.
Разрешённые теги Telegraph: a, aside, b, blockquote, br, code, em, figcaption, figure, h3, h4, hr, i, iframe, img, li, ol, p, pre, s, strong, u, ul, video. Без картинок и медиа.

Выработано консилиумом dsh + opencode + agy на реальных постах владельца. Критика владельца: «неудобный и плохо отформатированный дайджест с повторами каналов, без выделения заголовков, без читаемости и удобства для быстрого обзора ключевого за период».

ПРИНЦИПЫ: единица выдачи — сюжет (элемент ранга + его also_in), канал — только подпись; никаких блоков «по каналам»; метрики — мелким шрифтом в конце, не в начале; на каждый канал в полных карточках не больше 2 постов
(лишние уходят в «Коротко»); в «также» — по одному посту на канал, до 4 каналов, остальное «+N». Текст страницы собирается детерминированно (без ИИ) — никаких внешних вызовов.

МАКЕТ (сверху вниз):
1. Строка-вводная `p`/`i`: «Лента за день · 16 окт — 30 постов из 7 каналов · ≈3 мин чтения» (минуты = слова всей страницы / 180, минимум 1; для недели/месяца — диапазон «9–16 окт»).
2. `h3` «Главное» + `ul`: до 3 (день) / 5 (неделя, месяц) пунктов `li` по первым сюжетам: «<b>заголовок</b> — одно предложение сути (до 140 симв.)». Это экран быстрого обзора; если сюжетов меньше 3 — блока нет.
3. `h3` «Сюжеты» (если есть теги подписок — вместо одного блока идут разделы: сначала без тега, затем теги по алфавиту, как раньше; полные карточки получают первые N сюжетов по рангу, N = 6 для дня, 8 для недели, 10 для месяца).
   Полная карточка сюжета:
   - `h4` — заголовок: первая осмысленная фраза поста до 90 символов (по предложению; иначе по слову с «…»; эмодзи в начале сохранять; без перевода строки, без висящей точки);
   - `p` — суть: следующие 1–2 предложения того же поста, до 300 символов, обрезка по границе слова/предложения с «…»; если поста короче заголовка + 40 символов — только заголовок без «сути»; пустой текст — карточка без `p`;
   - `p` — подпись мелко: `i` «Канал · сегодня, 08:10» (для недели/месяца: «вчера, 19:19», «пн 12.10, 08:10»); если сюжет в нескольких каналах: « · также: Канал2, Канал3 (+2)» со ссылками на их посты;
     затем «Читать →» (ссылка на пост) и метрики словами-значками одной короткой строкой «👁 10K · ↗ 563» (только имеющиеся, ❤ и 💬 — если заметны), значки badges понятным текстом («📌 писали 4 канала», «🔥 в 6 раз больше пересылок, чем обычно», «🆕 новость», «📢 реклама»);
   - между карточками — `hr` только после первых трёх, дальше разделитель не нужен (воздух задаёт `h4`).
4. `h3` «Коротко»: `ul`, остальные сюжеты (до 25 строк): `li` — `<a href=пост>заголовок до 80 симв.</a> — Канал · 👁 1,2K`; посты без осмысленного текста (<40 символов, нет ссылки) в «Коротко» не показывать.
5. Подвал `p`: «Каналы в выпуске: bponline (12), truestorymedia (8), … · +3» (по числу постов в выпуске, до 8 названий), затем существующие плашки о неполных каналах и веб-метриках (ℹ️ …).
Страница для 50 постов должна быть < 60 КБ в JSON; названия каналов — из `channel_title`, резервно `channel_username`; все тексты — текстовые узлы без ручного экранирования.

ТЕСТЫ (даты — от переданного `now`; никаких абсолютных дат против реального «сейчас»): структура день/неделя/месяц; в полных карточках `h4` никогда не равен названию канала; не больше 2 полных карточек на канал; «Главное» (≥3 и <3 сюжетов);
«также»: один пост на канал, «+N»; обрезка по границе слова, заголовок без точки; «Коротко» не содержит пустых обрывков; теги-разделы; пустые метрики и пустой текст; очень длинные слова и ссылки; «≈N мин чтения»; размер 50 постов < 60 КБ;
реалистичный пример на 12–15 постах из текстов в docs/sprint/lenta-v3-sample.txt (создай файл-образец сам: 12 вымышленных, разнородных новостных постов с повторами каналов и 2 сюжетами в нескольких каналах). В итоге покажи текстовую визуализацию страницы для этого примера.
