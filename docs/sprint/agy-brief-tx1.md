КОНТЕКСТ. В TG1-fix в telegraph_publisher.py добавлены эвристики карточки: отбрасывание служебных строк пересылки («Переслано из …», «Forwarded from …»), баннеров-заголовков («🔥 Срочно в номер!»), замена голого URL в «Коротко» на «🔗 ссылка · домен». Те же дефекты есть у Ленты: общие хелперы `_clean_post_text`, `_extract_title_and_essence` и др. живут в feed_render.py, и Лента ими пользуется без этих эвристик.
Проверка живой страницы недели Ленты (https://telegra.ph/Lenta-za-nedelyu--09101610-10-16) и независимое ревью нашли ещё: (а) вводная «50 постов из 7 каналов» не совпадает с числом показанных карточек и пунктов «Коротко» (23); (б) смешанные формы дат («вчера», «сегодня», «пт 09.10») — страница статична, «сегодня» устаревает, как только её откроют на другой день; (в) в «Коротко» три заголовка обрываются многоточием посреди фразы, анонс одной карточки начинается с многоточия. ЧТО СДЕЛАТЬ.
1. Новый модуль post_text.py: перенеси в него (из feed_render.py и telegraph_publisher.py) чистые функции разбора текста поста: очистка служебных строк, извлечение заголовка и сути, нормализация КАПС, обрезка по слову, и эвристики TG1-fix (пересылка, баннер, голый URL → домен). Модуль без сетевого/БД кода и без импорта feed*/telegraph_publisher. feed_render.py и telegraph_publisher.py импортируют из него; прежние имена в feed_render (`_clean_post_text`, `_extract_title_and_essence`, …) остаются доступными (re-export), чтобы существующие тесты и импорты работали без правок.
2. Лента начинает использовать те же эвристики пересылки/баннеров (через общий модуль), без изменения ранжирования и состава постов.
3. Вводная строка Ленты показывает числа, совпадающие с реально выведенным (карточки + «Коротко»), либо явно разделяет «всего отобрано N, показано M» — выбери вариант с меньшим изменением формата и опиши.
4. Даты на странице: везде абсолютные («пт 09.10», при необходимости с временем), без «вчера/сегодня/сегодня в…» на статичной странице; в сообщении чата (тизер) относительные формы допустимы — не трогай, если они там.
5. Обрыв заголовков/анонсов: обрезать по границе слова/предложения, не начинать фразу с «…», не оставлять «висячие» предлоги/союзы в конце; если сократить без потери смысла нельзя — показывать заголовок целиком (в пределах лимита страницы).
ТЕСТЫ: на каждый пункт — примеры из реальной страницы (синтетические данные в духе тех, что в tests/test_feed_render*.py и tests/test_telegraph_digest_layout.py); эквивалентность: на существующих тестах Ленты ничего не ломается и порядок/состав карточек прежний. Даты относительные.
