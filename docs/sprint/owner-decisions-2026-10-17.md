## A. Пять вопросов на разговор

Для каждого: вопрос → варианты → рекомендация (уверенность) → что блокирует → цена ошибки.

### 1. Курсоры и слоты расписаний (ворота G1 перед T20)
- **Варианты:** (а) расписания папки ДЕЛЯТ поток (общий курсор на подписку); (б) независимые курсоры на пару (расписание, подписка); (в) **расписание = набор слотов с одним курсором**: утро 08:00 и вечер 19:00 внутри одного расписания делят поток (утро — ночные посты, вечер — дневные), а разные расписания папки (daily и weekly) независимы.
- **Рекомендация:** (в), уверенность средняя-высокая. Сверка dsh и Argon независимо показала, что (а) ломается при daily+weekly на одну папку, при Telegram+Email на один слот и при статусе `partial`; (в) даёт и «утро/вечер без дублей», и независимость периодов.
- **Блокирует:** T20–T22. **Цена ошибки:** переделка схемы и миграции (`docs/sprint/queue4-design.md` §2, §8 п.7).

### 2. Правила миграции и конфликты тегов (G1)
- Проект принял 6 правил без подтверждения владельца: папка по умолчанию «Основное», окно catch-up ≤ 7 дней, время в поясе пользователя, неподтверждённая почта → Telegram, удаление папки переносит каналы в «Основное», конфликт «канал в нескольких тегах» → старший период (monthly > weekly > daily).
- **Важно:** авто-создание обоих расписаний (daily и weekly) на папку НЕ сохраняет прежнее поведение полностью (все каналы папки получат обе периодичности).
- **Нужны цифры:** после влития PR #22 `prod_check.sh` покажет число каналов в нескольких тегах/периодах. Если 0–3 — авто-разрешение не нужно, достаточно ручного разбора. **Рекомендация:** подтвердить 5 правил, по конфликту тегов решать по цифре.

### 3. Почта: куда деваются существующие email-периоды
- **Варианты:** (а) мигрируют в `digest_schedules` с `delivery=email` (текущее решение roadmap §2); (б) остаются на legacy-пути `period` без миграции до выдачи JSON-контракта в ghsub (§0 roadmap: «почта как есть»); (в) выпуск JSON v1 в файловый спул для ghsub (`ghsub --once`).
- **Рекомендация:** (б) сейчас, (в) — когда ghsub готов (BaseSource + приём JSON v1). Сокращает T20 и убирает двойную миграцию. **Риск (в):** зависимость от готовности ghsub — подписчики почты не должны терять письма.
- **Побочное решение:** PR #19 (TG1) меняет формат письма (общий `build_content`) — принять новый формат или закрепить старый.

### 4. Лента после официальной ленты Telegram (ожидается вечером 18.10)
- **Варианты:** (а) пауза 48 ч на LV4, 👍/👎 и импорт папок; после изучения релиза оставить то, чего нет в клиенте (кросс-канальные сюжеты, резка рекламы, сводка недели/месяца одной страницей, почта через ghsub); (б) продолжать бэклог; (в) вывести Ленту из unagi.
- **Рекомендация:** (а), уверенность высокая (данных о релизе нет — мониторинг на сервере пришлёт письма).
- **Отдельно:** автодоставка Ленты по расписанию (T24c) противоречит исходному описанию «Лента — по запросу». Оставить как opt-in или убрать — решение владельца (Argon советует убрать; наблюдатель — оставить opt-in).
- **Отдельно:** «Главное» целиком повторяется в «Сюжетах» на странице недели — продуктовый вопрос (TX1 это НЕ меняет).

## E. Поправки наблюдателя к выводам Argon
- T19 (бэкап БД перед деплоем) уже выполнен (`ops/aiqu/backup_db.py` + CI), в плане Argon он как будущая задача — ошибка ввода. Но причина диска иная: несжатые снимки (BK1), а не docker-кеш.
- «dsh + владелец переезжают на РФ-сервер» невыполнимо: у агентов нет ssh и секретов, это ручная работа владельца; агенты могут подготовить скрипты и чек-листы.
- ghsub (BaseSource, `--once`, JSON v1) — отдельный репозиторий; в unagi делается только сторона выдачи контракта.
- «Сохраняет на 100% прежнее поведение» (авто-создание daily+weekly) — преувеличение, см. вопрос 2.
- Факты о странице недели Ленты (несовпадение «50 постов из 7 каналов» и 23 карточек, смешанные формы дат) получены чтением живой страницы небольшой моделью — владельцу стоит глазами проверить перед тем, как считать их багами.
- Построчные находки Argon по контейнеру содержали ложные срабатывания (побег через хардлинк через границу монтирования невозможен); сквозные выводы по стратегии и курсорам подтверждены независимой сверкой dsh.
