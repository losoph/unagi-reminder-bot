НОВАЯ МОДЕЛЬ (окончательная):
- Папка дайджеста = одна рассылка с ОДНИМ расписанием: только день, или только неделя, или только месяц; одно время (у ежедневной — опционально доп. слоты, только в настройках папки, один курсор). «Основной» — системная папка для подписок без папки.
- Канал состоит ровно в одной папке; курсор — один на подписку (как сейчас subscriptions.last_post_id). Таблицу курсоров на пару (расписание, подписка) из проекта УБРАТЬ.
- Мастер новой папки: период → время → (доставка — шаг скрыт, пока вариант один). Папка+подписка создаются одной транзакцией в конце; в существующую папку канал добавляется без шагов.
- Перенос канала / смена периода папки: подрезка курсора окном нового периода + пересчёт next_send_at. Удаление папки: [Перенести в Основной] / [Отписаться]. «Основной» не удаляется, пустой скрыт.
- Почта: email-подписки мигрируют в папки с delivery='email' (без UI); планировщик для email вызывает текущий email_digest; позже — запись JSON v1 для ghsub (контракт — раздел 3 файла Argon), старый email-путь period удаляется в переходе. Ворот G3 нет.
- Конфликты (канал в нескольких папках/периодах; неоднородный period внутри папки, включая tag IS NULL) — dry-run показывает, код 3, НЕ разрешает; владелец правит вручную до миграции; миграция строгая.
