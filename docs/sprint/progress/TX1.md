## TX1 Общий модуль разбора текста поста и дефекты Ленты
- Решение: Вынести чистые функции разбора текста, эвристики пересылок/баннеров, голых URL и правила обрезки без висячих предлогов/союзов в независимый `post_text.py` с сохранением re-export для обратной совместимости; вводную строку Ленты синхронизировать с реальным числом выведенных публикаций (карточки + «Коротко») с сохранением лаконичного формата; на статичной странице везде использовать абсолютные даты («пт 09.10, 12:00»), а в «Коротко» показывать заголовок целиком до 140 символов, не обрывая мысль посреди предложения.
- Компромисс: Число каналов во вводной строке считается по реально вошедшим в выпуск сюжетам (если не передано общее число подписок), что может отличаться от числа активных каналов, если часть не преодолела пороги отбора; дублирование блока «Главное» в «Сюжетах» сохранено намеренно как продуктовое поведение до решения владельца.
- Для следующей очереди: Продуктовое решение для владельца: блок «Главное» на длинных периодах (неделя/месяц) полностью повторяет первые карточки блока «Сюжеты» — определить, исключать ли эти посты из «Сюжетов» или оставить «Главное» только как оглавление.
