## RAWFEED Выгрузка постов Ленты для ghsub (kind: raw_feed) и почтовое окно недельных дайджестов — 18.10.2026

- **Решение:** unagi отдаёт ghsub сырые посты каналов Ленты с метриками раз в неделю (воскресенье, экспорт с 05:30 МСК, отказ после 08:00); отбор и ранжирование — в ghsub (решение владельца 18.10: «Лента в почту — один из источников ghsub»). Всё включается только при `EMAIL_DELIVERY=ghsub`.
- **Решение:** почтовый недельный дайджест при доставке через ghsub ставится на воскресенье 05:00 МСК (ghsub собирает письмо в 07:10, ящик должен быть готов к 06:15). Лента в Telegram идёт по времени пользователя.
- **Компромисс:** в шапке выпуска оставлено поле `recipient` (`unagi-<user_id>`) — ghsub его игнорирует, полезно для журналов; `items: []` пишется (ghsub ставит статус empty без письма).
- **Компромисс:** новые колонки `channel_posts.media_kind/is_forward/link_urls` допускают NULL: посты до миграции не отсеиваются как медиа/репосты.
