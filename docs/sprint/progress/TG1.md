## TG1 Переформатирование Telegraph-дайджеста — карточки и «Коротко»
- Решение: Для каждого канала детерминированно отбирать до 3 самых содержательных постов (по длине сути, наличию ссылки и объёму текста) в компактные карточки с тегом br между жирным заголовком и сутью, а оставшиеся посты сворачивать в маркированный список «Коротко» из одних ссылок-заголовков без дублирования названия канала; оглавление оставить простым компактным списком по каналам из-за отсутствия поддержки якорных ссылок в API Telegraph.
- Компромисс: Отказ от якорных ссылок требует ручной прокрутки к каналу, а детерминированный отбор до 3 карточек без ИИ может вынести в «Коротко» важную, но кратко сформулированную новость.
