ДЕФЕКТЫ, ВИДНЫЕ СЕЙЧАС (исправить все):
1. Заголовок обрывается на полуслове («…больше не…»), а «суть» продолжает ту же фразу («используют git, …»). Правило: заголовок — законченная мысль до 140 символов: первое предложение, если оно ≤140; иначе — первая смысловая часть до «:», « — », «, » (если в пределах 50–140), иначе обрезка по слову с «…». Если заголовок обрезан,
   «суть» = полный исходный текст с начала (до 300 символов, по границе предложения), а не «хвост». Если заголовок = целое первое предложение — «суть» = следующие 1–2 предложения (если они есть).

3. Пустые реплики попадают в топ («Хахахах», «Осень никого не щадит»). Полная карточка — только для постов с содержательным текстом ≥ 80 символов (после очистки); короткие уходят в «Коротко» (с заголовком = весь текст), а совсем пустые (<25 символов, без ссылки в тексте) не показываются нигде.
4. Шум форматирования: КАПС-заголовок («🦠КОВИД «УБИВАЕТ РАДОСТЬ»…») привести к обычному регистру (первая буква заглавная, остальное строчное, аббревиатуры ≤5 букв и «ИИ» оставить), цепочки одинаковых эмодзи (≥3 подряд: 🔴🔴🔴…) схлопнуть до одного, служебные хвосты каналов («@bugfeature | #chatgpt», строки только из хэштегов/упоминаний) убрать из «сути».
5. «Коротко»: показывать по ≤ 15 строк; для недели/месяца — сгруппировать по дням (`h4` «Пн, 12 окт» / «Вчера») внутри «Коротко»; порядок внутри дня — по рангу.
