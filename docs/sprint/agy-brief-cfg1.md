# CFG1 — единый модуль настроек вместо разрозненного os.getenv

Создай config.py: frozen dataclass-ы по областям (лента/ранжирование, источник каналов, email, telegraph, watchdog, время) с чтением переменных окружения в одном месте, теми же именами переменных, теми же значениями по умолчанию и теми же правилами разбора (int/float/bool), что сейчас в коде. Без pydantic и новых зависимостей. Значения читаются при вызове функции-фабрики (например settings() с lru_cache и функцией reset для тестов), чтобы тесты с patch.dict(os.environ) продолжали работать.
Переведи на config.py модули: feed.py, feed_ai.py, feed_ranking.py, ranking.py, feed_render.py, channel_source.py, email_digest.py, telegraph_publisher.py, watchdog.py, time_utils.py, reminders_ux.py, scraper.py. НЕ трогай main.py, data/database.py, ai_assistant.py, digest_alerts.py (их меняют другие треки) — для них только список переменных в отчёте.
Сначала составь таблицу «переменная → модуль → умолчание → тип» (в docs/sprint/progress/CFG1.md) и сверь, что после переноса ни одно умолчание не изменилось; тест tests/test_config.py проверяет умолчания и разбор.
