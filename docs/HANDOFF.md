
**Рабочая машина (itdirector, с 16.10).** Окружение собрано заново: `~/.venvs/unagi` (Python 3.12.15, ruff 0.16.8, зависимости из
`requirements.txt`). Google Drive теряет биты исполняемости у `*.sh` — если `git status` показывает «mode change 100755 → 100644»,
верните их: `git ls-files -s | awk '$1==100755{print $4}' | xargs chmod +x`. **libfaketime на этой машине не ставится** (Homebrew,
Tier 3, формула не собралась) — `time_shift_tests.sh` здесь не работает; при появлении Linux/другой машины прогнать там, а новые
тесты писать с датами относительно `now`.

CI (`.github/workflows/deploy.yml`) на push в `main`: ruff → `docker build` → `unittest` в контейнере → SSH-деплой
(`git pull origin main` → снимок БД `ops/aiqu/backup_db.py` в `storage/backups/*-predeploy.db`, 14 последних; нет снимка — деплой
останавливается → `docker compose up -d --build`). Секреты GitHub (`HOST`, `SSH_KEY`, `SSH_PORT`, `USERNAME`)
обновлены 10.10 и указывают на `aiqu-new` (деплои 10–12.10 прошли). Docker локально не нужен: чистый экспорт `main`
+ свежий venv из `requirements.txt` + `ruff 0.16.8` дали те же результаты (проверено).

Проверено на сервере/копиях 15.10:
- миграция на **реальной копии прод-БД**: 17 → 20 таблиц, ни одна строка существующих таблиц не изменилась, повтор идемпотентен, `integrity_check = ok`;

## 4. Деплой и откат

1. **Пуш в `main` = деплой на прод.** Делает только владелец или по его явному «да» (`git push origin main`).
2. После пуша следить: `gh run watch -R losoph/unagi-reminder-bot`; затем `ssh aiqu-new 'docker logs --since 5m unagi-bot | tail -50'`.
3. Дымовая проверка в Telegram: `/feed` → добавить канал (пересылкой/ссылкой) → «День» → открывается страница Telegraph с карточками;
   тег канала → раздел на странице; у владельца сессии есть «➕ Из моих подписок»; существующие функции (напоминания, закладки,
   дайджесты, `/export`) работают. В логах строка `feed_build user=… period=… cache=hit|miss duration_ms=…`.
4. **Откат кода:** `git revert -m 1 <merge-коммит>` или `git revert <диапазон>` + пуш (CI передеплоит). Миграции только добавляют
   таблицы/колонки, поэтому старый код спокойно работает на мигрированной БД — восстанавливать БД из бэкапа для отката кода **не нужно**.
5. Экстренно на сервере: `cd ~/projects/unagi-reminder-bot && git checkout d539c97 && docker compose up -d --build` (до следующего пуша).
6. Восстановление БД (только при порче данных): остановить контейнер, заменить `storage/bot_data.db` файлом из `storage/backups/`, запустить.

## 5. Агенты и модели (как продолжать работу)

- **Роли:** Claude — наблюдатель (проверяет каждый коммит: ruff, тесты, чтение диффа, воспроизведение находок ревью); **agy**
  (Antigravity CLI, Gemini) и **opencode** (провайдер Tokenn, GPT) — исполнители и перекрёстные ревьюеры. Подробности и шаблоны —
  `tools/agents/README.md`, три непересекающихся слоя наблюдения — `docs/sprint/agy-progress-protocol.md`.
- **Каждая сессия агента — отдельная вкладка терминала** (владелец хочет видеть мысли); одна строка ASCII, без `cd` в кириллический путь.
- **Вкладки не наследуют окружение наблюдателя.** agy без прокси отвечает `User location is not supported`: экспортировать
  `HTTPS_PROXY/HTTP_PROXY=http://127.0.0.1:18080` (туннель `gostpx`; алиас `setproxy` в `~/.zshrc` ведёт на мёртвые порты). Ключи (`TOKENN_API_KEY`,
  `OPENROUTER_API_KEY`) лежат в `~/.zshrc`: opencode запускать через `zsh -ic` и с флагом `--standalone`.
- **Выбор модели на задачу — через Jev** (`tools/agents/route.sh <agent> <вид> "<описание>" [--dry-run]`, OpenRouter Decisions API,
  решение пишется в `.agents/routes.ndjson`). Выбор один раз на задачу, не на каждый запрос (кеш промптов). Для моей собственной модели
  `route.sh claude …` только рекомендует — переключает владелец в меню. 15.10: Sonnet 5.5; перед финальным аудитом/пушем — рассуждение xhigh.
- **Уроки по моделям (в `routing.json`):** `codex-5.3` и `gpt-5.5` — лимит вывода 4k токенов: обрезают большие записи файлов (T24-fix, пустой `write`),
  годятся для коротких ревью; для кода и больших тестов — `gpt-6.1-sol` (16k). `agy -c` продолжает **последний** разговор — после любого
  постороннего запуска agy указывать разговор явно или начинать новый. Супервизор `agy_supervise.sh` на повторных попытках откатывает
  дерево (обрывки в `.agy/partial-*`) — если нужно сохранить работу, `AGY_KEEP_TREE=1`.
- **Единая точка входа для агентов (с 16.10):** `tools/agents/agents.sh help` — `status`, `pick`, `run`, `check`, `watch`, `route`, `report`. Исполнитель по умолчанию — **dsh**
  (DeepSeek Harness, `npx dsh web`, ключ хранит сам dsh); opencode — только короткие сверки и только с решением Jev (бюджет 5 млн токенов на сессию, `budget.json`, `budget.json`).
  Приоритет экономии токенов: opencode > deepseek > Jev > Claude > agy. Подробности, калибровка расхода и эффорт Off/Low/High/Max — `tools/agents/README.md`.
- **Простые решения через Jev:** `tools/agents/decide.sh "вопрос" вариант=описание … --default <безопасный>` — закрытый список, порог
  уверенности 0.7, эскалация к человеку (код 10); журнал `.agents/decisions.ndjson`. Только советует: push, откат прода, удаление данных
  решает наблюдатель/владелец. Ключ OpenRouter берётся из окружения или из `~/.config/agent-tools/env` (0600, строки `OPENROUTER_API_KEY=…`);
  без ключа `route.sh` и `decide.sh` честно откатываются на статическую политику / «решает человек».
- **Монитор:** `scripts/agy_watch.sh digest 600` и `tools/agents/oc_digest.py` (Monitor-задачи живут ≤30 мин, перезапускать).
